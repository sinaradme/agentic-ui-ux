## Acceptance checks

- The opening states who the guide helps and what to do.
- A reader can choose one tool, install it, and copy a prompt without opening another file.
- Existing interfaces and new websites have different starter paths.
- Official screenshots have descriptive alt text, attribution and clear evidence labels.
- Native users are routed away from web-only dependencies.
- No popularity-based quality ranking or fake benchmark is presented.
- Detailed setup, catalog and benchmarks remain available without cluttering the main page.

## Remaining verification

No installation or independent comparative benchmark has been run. No external reader study or live GitHub mobile-layout test has been conducted. Official screenshots were inspected as images, not as live interactive apps. The externally hosted GIF may change or become unavailable. Review rendered README behavior and run real experiments before making stronger claims.

The editorial goal is fast task completion, not the longest possible tool list. New entries should improve a specific reader decision or provide reproducible evidence.
