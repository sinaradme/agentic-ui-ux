# Contributing

Thank you for helping make agent-assisted design more practical and evidence-driven.

Propose additions or corrections through a GitHub issue or pull request. Include an upstream link, exact skill/project name, intended use, license, most recent relevant activity date, verified installation instructions and framework/agent compatibility. Explain which gap the tool fills and whether it overlaps with an existing entry.

Prefer actively maintained, free open-source resources. Flag mixed licensing, paid dependencies, low adoption, unverified claims or risky installation behavior. Do not submit a marketing ranking as a benchmark result.

For hands-on comparisons, follow the [evaluation protocol](benchmarks/README.md). Provide reproducible conditions and original or licensed evidence, including unsuccessful runs. Never upload secrets, proprietary customer assets or private user data.

Maintain concise, English-language documentation. Link upstream rather than copying large portions of third-party instructions. Keep recommendations actionable, distinguish observed facts from editorial judgments, and update the research date when rechecking metadata. By contributing, you agree to license original contributions under this repository's MIT license.

For changes to agent selection, update the skill's catalog and decision rules together. Add a representative fixture and run `node skills/agentic-ui-ux/scripts/test-plan.mjs`. Keep installation examples separate from executable actions. Do not claim installation or visual-quality validation based on planner fixtures alone.
