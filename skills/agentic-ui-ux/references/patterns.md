# Pattern discovery starter index

This index is intentionally small, not a complete registry. Use it to find a concrete reference, then retrieve and read the actual source with `source.mjs`. For more patterns inspect the routed official registry/docs or upstream example galleries. A pattern is an inspiration/behavior reference, not an installation recommendation. Never reuse a trademark, asset or unlicensed code. The source must be inspected for the actual task.
