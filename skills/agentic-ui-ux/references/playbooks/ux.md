# UX and user flows

Identify primary user task, entry, success, failure and return paths. Map information architecture before styling. Write the key actions in plain language; avoid unnecessary steps or decisions. Include empty, loading, error, disabled, success and permission states where relevant. Keep sensitive/financial/medical flows explicit and preserve business rules. Test keyboard and touch navigation and task completion. Do not invent backend functionality. Use UI/UX Pro Max for planning only when needed; for an existing Impeccable setup use critique/onboard for a narrow flow.

Use [capabilities.json](../capabilities.json) to select only the relevant capability and [priority policy](../priority-policy.json) for external tools. The playbook works without installing an external skill; it is not a substitute for verified specialist guidance when a gap remains.
