# Interaction design

Define the user action, feedback, resulting state and cancellation path. Prefer semantic native controls; verify focus management, touch targets, keyboard shortcuts, dialog escape/return focus and loading feedback. Gesture-driven motion should track input, be interruptible and have a non-gesture alternative. Do not replace working interactions for aesthetic reasons. Use Emil gestures or animate-expo for a real specialist gap, not all motion skills. Test actual input and failure states.

Use [capabilities.json](../capabilities.json) to select only the relevant capability and [priority policy](../priority-policy.json) for external tools. The playbook works without installing an external skill; it is not a substitute for verified specialist guidance when a gap remains.
