# Design systems

Inventory tokens, variants and primitives. Establish a semantic naming scheme for colors, spacing, radius, elevation, type and motion. Reuse existing patterns; keep changes local to the requested scope. Map new tokens to light/dark and accessibility needs, not one-off hex values. Verify consistent states across multiple components. Use UI/UX Pro Max when a design-system planning gap is documented; preserve a compatible existing primary owner. Do not rewrite the design system just to match a sample.

Use [capabilities.json](../capabilities.json) to select only the relevant capability and [priority policy](../priority-policy.json) for external tools. The playbook works without installing an external skill; it is not a substitute for verified specialist guidance when a gap remains.
