# Art direction

Start with product, audience, tone, brand assets, existing tokens, and references. Decide one visual thesis in one sentence. Define three concrete choices (type, layout, imagery) and three exclusions. For a new landing page use a bold but coherent composition; for an existing product preserve identity and task clarity. Prefer real project assets and purposeful whitespace over generic gradients, floating cards and decorative badges. Do not copy another brand or use unlicensed assets. If an external primary skill is justified, use one owner only: Taste for new web work, Impeccable for existing web, UI/UX Pro Max for planning. Existing compatible owner wins. Check actual output against the brief, not against an arbitrary aesthetic.

Use [capabilities.json](../capabilities.json) to select only the relevant capability and [priority policy](../priority-policy.json) for external tools. The playbook works without installing an external skill; it is not a substitute for verified specialist guidance when a gap remains.

For `designMode: rebuild`, the [rebuild contract](../rebuild.md) overrides preservation/minimal-change defaults for visual composition. Inspect actual external pattern sources and propose three structurally distinct candidates per scoped section; reuse engineering primitives only if suitable. No automatic new dependency or purposeless animation.
