# Typography and color

Use the project's font and color tokens first. Define heading/body/label sizes, weights, line heights, readable measure and semantic color roles. Avoid unnecessary font families and random type sizes. Check contrast and focus visibility, real text lengths, localization, and text scaling. Do not use color alone to convey status. For a typography-only task, apply these rules and an already-installed compatible command (Impeccable typeset/colorize) rather than adding a broad skill by default.

Use [capabilities.json](../capabilities.json) to select only the relevant capability and [priority policy](../priority-policy.json) for external tools. The playbook works without installing an external skill; it is not a substitute for verified specialist guidance when a gap remains.
