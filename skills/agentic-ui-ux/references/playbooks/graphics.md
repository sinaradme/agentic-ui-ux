# Graphics and illustration

Start with project-owned licensed assets and a purposeful art direction. Use crisp icons with consistent stroke, appropriate SVG/chart semantics and descriptive alternatives. Product screenshots must be real or clearly marked mockups; avoid fake metrics, invented data and decorative AI filler. For animated product demos consider Stageshow only when the task calls for it; for one decorative effect inspect a compatible free Magic UI component. Match the design system, test asset loading and reduced motion. Do not copy screenshots as product assets without checking rights. If no asset or generator is available, state the gap rather than pretending a placeholder is final.

Use [capabilities.json](../capabilities.json) to select only the relevant capability and [priority policy](../priority-policy.json) for external tools. The playbook works without installing an external skill; it is not a substitute for verified specialist guidance when a gap remains.
