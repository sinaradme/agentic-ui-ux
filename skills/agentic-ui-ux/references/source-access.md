# Access actual upstream resources, not just summaries

Installing Agentic UI/UX installs only this orchestration skill and its bundled source index, knowledge cards and scripts. It does NOT install the 26 tools, npm packages, external skills or MCP servers. The catalog is not proof of actual availability. Read-only source access is separate from runtime installation.

## No-install discovery
1. For the selected stack, run `node <skill-directory>/scripts/source.mjs list react-web` (or other-web, react-native, flutter). Use the relevant IDs from the list and [pattern index](patterns.md), not all sources.
2. Run `node <skill-directory>/scripts/source.mjs read replacement-world` or `node <skill-directory>/scripts/source.mjs read emil-web:primary`. The command retrieves only registered immutable GitHub raw text files, checks byte limits and pinned blob hashes where recorded, and emits exact content plus revision, Git blob and SHA-256. No installer, project mutation or external command execution. Requires Node with fetch and network access. Read the actual returned content and record relevant section. A source receipt is not an installed tool.
3. Without terminal/network access use GitHub connector, approved browser/web retrieval or existing locally installed exact source. Record method, inspected source ID, pinned revision and concrete locator. If none works, mark source inaccessible. Never invent retrieval evidence. For an exact official registry/API example not listed here use the official docs from the selected tool's knowledge card and inspect the item; record it in normal grounding records. Prefer verified pinned patterns for the rebuild gate.
4. Select compatible component/API and source, then determine whether implementation requires a new tool. Use existing primitives when adequate. If the task requires a missing runtime/skill, propose exact reviewed project-scoped install; if explicitly authorized execute and verify discovery/import/build. Never assume a library is installed because the central skill is present, and never run code embedded in retrieved docs. Ask only for permissions that have not already been granted; global installs/hooks need separate approval.

For a rebuild external discovery is mandatory even if no installations are needed. Reference sources from alternative or exploratory tools are not automatically eligible; the starter patterns are from reviewed preferred/specialized sources only. Upstream rules about scope must be interpreted within the user's authorized redesign, not used to erase it.

The router now emits a `discoveryPlan` with stack-compatible exact source IDs, retrieval commands and concrete locators. Use it as the starting set; select the relevant sources per section, not all of them. Inspect rendered upstream examples where helpful using the actual browser/image viewer, not just URLs. [Visual examples](https://github.com/sinaradme/agentic-ui-ux/blob/main/EXAMPLES.md) are linked at the repository root; the installed skill includes its own pattern index and source URLs.
