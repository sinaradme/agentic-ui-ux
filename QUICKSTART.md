# Quickstart

[Home](README.md) · [Tools](TOOLS.md) · [Workflows](WORKFLOWS.md)

## 1. Understand what you are installing

A central connector, not a UI library. The connector installs full original skills on demand. A component, package or MCP may need its own official direct action.

## 2. Recommended: install only Agentic UI/UX

```sh
npx skills add sinaradme/agentic-ui-ux --skill agentic-ui-ux
```

Run from the target project. Choose your active agent and project scope.

### Manual alternatives

You may install any provider directly using its own official instructions instead of using this connector. [Tools](TOOLS.md) links to the originals. For example, Impeccable documents `npx impeccable install`, and UI/UX Pro Max documents its own setup in its [repository](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). Review versions and permissions.

## 3. Use it in your agent chat

```text
Use agentic-ui-ux to redesign this page with professional motion.
Connect and invoke the actual original tools and use their own workflow.
```

The agent writes the task JSON, executes [direct connection](skills/agentic-ui-ux/references/direct-connect.md), and invokes the selected original skills. Authorize installation when needed; hooks/broad provider permissions require specific approval.

## 4. Add UI components only as needed

Use the original shadcn/Magic UI native skills and official CLI to inspect and add the exact registry item. Reuse an existing compatible library; do not reinitialize or overwrite without authorization.

## 5. Give the agent visual feedback

Use the original provider's visual checks and a working browser/device. Request actual rendered screenshots and motion/interaction tests. A passing install does not mean the design passed.

## 6. Optional: install this guide's skill

The install command above is the recommended central entry. A read-only repo link is not local installation or native invocation.

## 7. Reproducibility and safety

Original files are pinned and verified; no global installs or silent overwrites. Host activation, permissions and external runtime availability are separate checks. [Quality evidence](DIRECT-CONNECT-QC.md).
